# Key Features

Live speech recognition and multilingual translation
AI-powered text-to-speech generation
Audio recording, uploading, editing, and playback
Multiple projects with saved transcription and translation data
Export to TXT, DOCX, SRT, CSV, XLSX, MP3, and WAV (some formats require Pro)
Web-based interface with online and offline application configurations

# Tech Features
Python, Flask, PyTorch, Faster-Whisper, CTranslate2, NLLB, Vosk, Piper TTS, Edge TTS, HTML, CSS, JavaScript, PostgreSQL, Redis, SQLAlchemy, Docker, Nginx.
